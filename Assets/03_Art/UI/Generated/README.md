# Sand Color generated UI kit

Reference style: the project's existing pastel sand, soft toy, and beach UI artwork.

- `Buttons`: nine blank textured buttons intended for TextMesh Pro labels.
- `Icons`: ten circular action icons.
- `Badges`: numbered stage badges 01–08.
- `Bars`: nine pill backgrounds plus a progress frame/fill pair.
- `Panels`: three cream nine-slice-ready panel sizes.
- `SandSwatches`: eight colored sand selection tiles.

All art is PNG with transparency. Keep text separate in Unity so localization and state changes remain easy.
